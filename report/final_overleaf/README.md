# Final report Overleaf package

## Upload

1. Create a blank Overleaf project.
2. Upload `main.tex` and the complete `images` folder.
3. Set `main.tex` as the main document.
4. Select pdfLaTeX as the compiler.
5. Compile the project two times so that all references resolve.

## Report structure

- Abstract
- Introduction, split across at least two source-controlled pages
- Literature review, split across at least three source-controlled pages
- Proposed approach, split across at least two source-controlled pages
- Implementation, split across at least two source-controlled pages
- Result and analysis, with verified tables and MATLAB figures
- High-resolution PNG protocol flowchart and class diagram in `images/`
- Conclusions and future work, 194 words
- References

## Evidence boundary

The numerical results come from `results/v3/summary`. The report compares the fixed
3000 ms baseline with Protocol v3. It does not use legacy mode as the final baseline.
